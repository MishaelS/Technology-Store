# Фотографии товаров

Памятка: какие фото нужны, чтобы товар хорошо смотрелся на сайте, и как их добавить.
Требования взяты из того, как сайт показывает картинки: карточки каталога, страница товара с лупой, галерея, корзина, конфигуратор.

## Общие требования

| Что | Как лучше |
|---|---|
| Формат | **JPEG** или **WebP** для фото, **PNG** — если фон прозрачный. GIF тоже принимается. **SVG нельзя**: сайт его отклоняет из соображений безопасности |
| Размер файла | до **5 МБ** (больше сайт не примет). Хорошо сжатое фото обычно весит 200–600 КБ |
| Пропорции | **4:3**, горизонтальное. Везде на сайте фото показывается в рамке 4:3, а то, что не влезает, обрезается по краям |
| Разрешение | **1600×1200 px**: хватит и для лупы на странице товара. Минимум 800×600 |
| Фон | **белый или светло-серый однотонный**, либо прозрачный PNG. Одинаковый фон у всех товаров — магазин выглядит цельным |
| Положение | товар **по центру**, отступ от краёв около 10%: иначе обрезка рамкой и лупа «съедят» края |
| Свет | ровный, без жёстких теней и бликов на глянце |
| В кадре | только товар: без рук, чужих коробок, проводов и мусора |

В тёмной теме сайт сам немного приглушает фото — отдельные версии делать не нужно.

## Сколько фото на товар

- **Главное фото** — товар целиком спереди. Его видно в каталоге, в корзине, в конфигураторе и первым на странице товара.
- **Ещё фото** — до **10 штук**. В карточке каталога они листаются, пока курсор лежит на карточке; на странице товара видны миниатюрами под главным фото. Обычно хватает **3–5**.

## Какие ракурсы снимать

| Категория | Главное фото | Дополнительные фото |
|---|---|---|
| **Процессор** | крышка с маркировкой, прямо | обратная сторона (контакты или ножки), под углом 45°, коробка |
| **Материнская плата** | вся плата сверху | сокет крупно, задняя панель разъёмов, слоты памяти и M.2, коробка |
| **Видеокарта** | вентиляторы спереди | сбоку (видна толщина), разъёмы видеовыходов, разъём питания, задняя пластина |
| **Оперативная память** | планки спереди, весь комплект | наклейка с характеристиками, сбоку (высота радиатора), подсветка — если есть |
| **Накопитель** | лицевая сторона с наклейкой | обратная сторона, разъём, рядом с линейкой или монетой для масштаба (M.2) |
| **Блок питания** | сбоку, видна наклейка с мощностью | задняя сторона (разъём и выключатель), модульные разъёмы, комплект кабелей |
| **Корпус** | спереди под углом 3/4 | сбоку через стекло, сзади, верхняя панель с кнопками, внутри без боковой стенки |

## Другие картинки на сайте

| Где | Что нужно |
|---|---|
| **Новости и акции** | горизонтальный баннер **16:9**, 1280×720 px; главное держать в центре кадра |
| **Аватарка в личном кабинете** | квадратное фото от 256×256 px; в кружке углы обрезаются |

## Как добавить фото к товару

1. Войти под сотрудником, менеджером или администратором.
2. **Админка → Товары**, у нужного товара нажать карандаш (или «Новый товар»).
3. Блок **«Картинка»**:
   - **главное фото** — перетащить файл в поле или нажать на поле и выбрать файл (можно и вставить из буфера: Cmd+V / Ctrl+V);
   - **«Ещё фото»** — перетащить сюда сразу несколько файлов или нажать «Добавить фото». Лишнее фото убирается крестиком.
4. Нажать **«Сохранить»**.

Имена файлов не важны: сайт сам даёт загруженным файлам случайные имена и хранит их в папке `uploads/`.
Вместо загрузки можно вписать ссылку на картинку (`https://…` или путь на сайте `/…`).

## Фото сразу для всех товаров (из папки)

Собранные фото лежат в `resources/photos/products/<название-товара>/01…`.
Название папки — имя товара маленькими буквами через дефис: `AMD Ryzen 7 7800X3D` → `amd-ryzen-7-7800x3d`.

1. Подготовить веб-версии (на компьютере, нужен Pillow):
   ```bash
   python3 backend/scripts/prepare_product_photos.py
   ```
   Каждое фото становится 1600×1200 WebP: белые края обрезаются, товар целиком по центру на белом фоне,
   мелкие миниатюры пропускаются. Рядом кладётся маленькая копия `NN-sm.webp` (480×360, ~9 КБ):
   её сайт показывает в карточках, корзине и миниатюрах, большое фото — только на странице товара. Результат — `resources/photos/web/` и список `manifest.json`. Исходники не меняются.
2. Подключить их к товарам:
   ```bash
   ./run.sh photos
   ```
   Первое фото папки становится главным, остальные — «Ещё фото». У товаров без фото — **заглушка**
   (нарисованная картинка с иконкой категории, брендом и характеристикой).
   Фото, загруженные вручную в админке, команда не трогает. Запускать можно сколько угодно раз.

Фото, загруженные через админку, сервер тоже сам уменьшает: рядом с файлом появляется `<имя>-sm.webp`.

Картинка первого слайда главной («Собери свой ПК») — настоящие комплектующие, сложенные вместе, на прозрачном фоне:

```bash
python3 backend/scripts/make_hero_collage.py
```

Какие фото взять и где их положить — список `LAYOUT` в начале скрипта. Без файла `hero-build.webp` на слайде остаётся значок.

Если картинка на сайте не загрузилась (файл удалили, ссылка не работает), вместо неё показывается
серая заглушка `resources/demo/placeholder.svg`.

## Перед загрузкой: короткий чек-лист

- [ ] горизонтальное фото 4:3, не меньше 800×600 (лучше 1600×1200)
- [ ] JPEG, WebP или PNG, файл меньше 5 МБ
- [ ] светлый однотонный фон, товар по центру с отступами
- [ ] главное фото — товар целиком спереди, ещё 3–5 ракурсов из таблицы
- [ ] в кадре только товар, нет бликов и жёстких теней

## Права на фото

Используйте **свои фото** или **официальные пресс-фото производителя** (их обычно разрешают брать магазинам — проверьте условия на сайте производителя).
Чужие снимки из других интернет-магазинов без разрешения не берите.
