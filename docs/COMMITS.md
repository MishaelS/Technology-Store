# Оформление коммитов

Формат:

```
тип: короткий заголовок, что сделано

- подробность 1
- подробность 2
```

Тип пишется с маленькой буквы, после него двоеточие и пробел. Описание после пустой строки нужно не всегда; если оно есть, каждый пункт начинается с тире.

| Тип | Когда |
|---|---|
| `add` | добавили файлы, ресурсы, зависимости, документацию |
| `feat` | новая функция на сайте или в API |
| `fix` | исправили ошибку |
| `rem` | удалили ненужное |

Примеры:

```
feat: бесконечная прокрутка в каталоге

- порции по 20 товаров по курсору
- скелетоны при загрузке
```

```
fix: бонусы списывались больше 30% заказа
```

```
rem: старые заглушки API
```
