# Технологии проекта

Какие технологии используются в Technology-Store, для чего каждая нужна и где её найти в коде.
Версии библиотек взяты из `backend/requirements.txt` и `docker-compose.yml`.

## Как всё связано

```
Браузер
   │  http://localhost:5173
   ▼
nginx (контейнер frontend)
   ├── /            → сайт: frontend/index.html и frontend/src/*
   ├── /resources/  → иконки и демо-картинки (папка resources/)
   ├── /uploads/    → загруженные картинки и аватарки (папка uploads/)
   └── /api/        → передаёт запросы бэкенду
                         │
                         ▼
               FastAPI (контейнер backend, порт 8000)
                         │  SQLAlchemy + psycopg
                         ▼
               PostgreSQL 16 (контейнер db, порт 5432)
```

Сайт обращается к API по своему же адресу (`/api/...`), поэтому снаружи нужен только один порт — 5173.

### Что сделано своими силами на бэкенде

| Часть | Файл | Что делает |
|---|---|---|
| Права по ролям | `app/permissions.py` | одно место, где описано, какая роль что может; проверяется в каждом запросе |
| Прокрутка по курсору | `app/pagination.py` | каталог и новости отдаются порциями без повторов и пропусков |
| Совместимость сборки | `app/services/compatibility.py` | 7 правил: сокет, тип и слоты памяти, мощность блока питания, длина видеокарты, форм-фактор, встроенная графика; оценка мощности |
| Бонусы и заказы | `app/services/bonus.py`, `app/services/orders.py` | начисление и списание бонусов, статусы заказа |
| Переводы ответов API | `app/i18n.py` | сообщения API на языке пользователя (заголовок `Accept-Language` или `?lang=`) |
| Загрузка картинок | `app/routers/uploads.py` | тип файла проверяется по первым байтам (PNG, JPEG, WebP, GIF), SVG запрещён |
| Бэкапы | `app/backups.py` | вся база в JSON и загруженные картинки в одном `.zip`; восстановление одной транзакцией; автобэкап (выключен) |
| Демо-данные | `app/demo.py`, `scripts/make_demo_images.py` | `./run.sh demo`: товары с картинками, новости, клиенты, заказы; картинки рисуются в SVG |
| Фото товаров | `scripts/prepare_product_photos.py`, `app/photos.py` | веб-версии фото (Pillow: 1600×1200 WebP на белом фоне); `./run.sh photos` — настоящие фото или заглушка |
| Картинка первого слайда | `scripts/make_hero_collage.py` | комплектующие с вырезанным фоном и тенями, сложенные вместе, для слайда «Собери свой ПК» |

## База данных

| Технология | Версия | Для чего |
|---|---|---|
| **PostgreSQL** | 16 (`postgres:16-alpine`) | основная база |
| **JSONB** | — | характеристики товаров (`specs`) и список фото (`images`): у каждой категории свой набор полей |
| **Adminer** | `adminer` | просмотр базы в браузере, http://localhost:8080 |

При старте бэкенд сам применяет миграции (`alembic upgrade head`) и, если база пустая, заполняет её тестовыми данными (`backend/entrypoint.sh`).

## Фронтенд

**Обычные HTML, CSS и JavaScript без фреймворка и без сборки.** Код — ES-модули (`import`/`export`), браузер загружает их как есть, nginx только раздаёт файлы. Это сделано специально: проект учебный, код читается напрямую, без шага сборки.

| Технология | Для чего |
|---|---|
| **ES-модули JavaScript** | весь код сайта, `frontend/src/` |
| **CSS (один файл)** | все стили, `frontend/src/style.css`; цвета и размеры — переменные (`--accent`, `--surface`…) |
| **nginx** 1.27 (`nginx:1.27-alpine`) | раздаёт сайт, иконки и загруженные файлы, передаёт `/api/` бэкенду; сжимает текст (gzip), картинки кэшируются браузером |
| **Шрифты Manrope и JetBrains Mono** | Google Fonts: основной текст и цифры (цены, байты фона) |
| **Свои SVG-иконки** | 100 иконок в `resources/icons/`, рисуются через CSS-маску и красятся цветом текста |

### Свои модули фронтенда

| Модуль | Что делает |
|---|---|
| `ui.js` | создание элементов (`h()`), поля с названием внутри, аватарки, скелетоны, пустые состояния |
| `router.js`, `app.js` | маршруты по адресу `#/...`, шапка, подвал, переходы между страницами |
| `api.js` | все запросы к API: токен, язык, ошибки, загрузка файлов |
| `i18n.js` | переводы интерфейса: получает их у API (`/api/i18n/<язык>`), а тот читает `resources/locales/{ru,en}.json` |
| `infinite.js` | бесконечная лента: подгрузка порциями при прокрутке |
| `admin-list.js` | списки админки: поиск, фильтры, лента строк, карточки строк на телефоне |
| `dropdown.js`, `number-field.js` | свои выпадающие списки и стрелки числовых полей вместо стандартных |
| `image-drop.js` | загрузка картинок: перетаскивание, выбор файла, вставка |
| `effects.js` | волна от клика, появление блоков при прокрутке, плавный отсчёт чисел |
| `hex-background.js` | фон из байтов: шум Перлина, волна при смене страницы |
| `theme.js` | светлая и тёмная тема |
| `images.js` | своя загрузка картинок: маленькие копии в карточках, очередь с приоритетом (ближние к экрану — первыми, не больше 6 сразу), загрузка заранее, плавное появление, память загруженного, предзагрузка по наведению |

### Возможности браузера, на которых всё держится

| Что | Где используется |
|---|---|
| **View Transitions API** | волна при смене страницы и при смене темы |
| **IntersectionObserver** | бесконечная лента, появление блоков, отсчёт чисел на главной |
| **MutationObserver** | свои выпадающие списки и числовые поля появляются сами у новых элементов |
| **Canvas 2D** | фон из байтов |
| **Fetch** | все запросы к API, отправка файлов |
| **Drag and Drop + File API** | перетаскивание картинок, аватарок и бэкапов |
| **localStorage** | токен входа, выбранная тема, свёрнутые фильтры |
| **matchMedia** | тема системы (`prefers-color-scheme`), уменьшение движения (`prefers-reduced-motion`) |
| **CSS** `:has()`, `color-mix()`, `@property`, `scroll-snap`, `clip-path`, сетки и flex | вёрстка, слайдер, кольцо оценки сборки, анимации |

## Запуск и окружение

| Технология | Для чего |
|---|---|
| **Docker и Docker Compose** | четыре контейнера: `db`, `backend`, `frontend`, `adminer` (`docker-compose.yml`) |
| **`run.sh`** (bash) | все команды одной строкой: `start`, `stop`, `test`, `demo`, `reset`, `typecheck`… (`./run.sh help`) |
| **`.env`** | пароли и настройки; в репозитории только пример `.env.example` |

| Контейнер | Образ | Порт | Что это |
|---|---|---|---|
| `db` | `postgres:16-alpine` | 5432 | база данных |
| `backend` | `python:3.12-slim` + `backend/requirements.txt` | 8000 | API и документация `/docs` |
| `frontend` | `nginx:1.27-alpine` | 5173 | сайт |
| `adminer` | `adminer` | 8080 | просмотр базы |

Папки на компьютере, подключённые к контейнерам: `uploads/` (загруженные картинки) и `backups/` (бэкапы). Обе не попадают в git.

Подробнее — [docs/SETUP.md](SETUP.md).
