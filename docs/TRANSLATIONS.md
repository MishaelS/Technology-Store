# Переводы (ru / en)

Все тексты сайта лежат в одном месте: `resources/locales/<язык>.json` ([ru.json](../resources/locales/ru.json), [en.json](../resources/locales/en.json)).

## Кто их использует

- **Бэкенд** берёт оттуда сообщения об ошибках, тексты проверок конфигуратора, названия категорий и уровней ПК. В коде это выглядит так: `t("errors.cart_empty")` или `t("errors.bonus_limit", max=100)`.
- **Фронтенд** берёт из тех же файлов все надписи интерфейса: напрямую из папки или через API (`GET /api/i18n` — список языков, `GET /api/i18n/en` — все тексты языка).

## Как выбирается язык

Параметр `?lang=en` → заголовок `Accept-Language` → по умолчанию `ru`. Если текста нет в нужном языке, берётся русский.

## Правила

- Ключи сгруппированы по разделам сайта: `nav`, `catalog`, `cart`, `builder`, `admin`, `errors`…
- Подстановки пишутся в фигурных скобках: `"Заказ #{id} оформлен"`. Имена `lang` и `default` для них не используйте: это параметры функции `t()`.
- В каждом языке должны быть одинаковые ключи и одинаковые подстановки.
- Новости, факты и описания товаров — это данные в базе, они не переводятся.

## Проверка

```bash
./run.sh locales
```

То же самое проверяют автотесты в `test_i18n.py`.

## Новый язык

Скопировать `ru.json`, например, в `de.json`, перевести значения и запустить проверку. Бэкенд подхватит язык сам.
