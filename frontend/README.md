# Фронтенд (упрощённый)

Простой интерфейс без дизайна. Его задача — показать, как работает каждая функция сайта, и служить основой для настоящего дизайна.

Открывается по адресу **http://localhost:5173** после `./run.sh start`.

## Как устроено

- Обычные HTML + JavaScript (ES-модули), без сборки и без `npm`. Файлы отдаёт nginx в Docker, поэтому правки видны сразу после обновления страницы.
- Адреса страниц живут после `#`: `#/catalog?category=gpu`, `#/product/7`, `#/admin?section=orders`.
- Все данные приходят из API (http://localhost:8000). Описание API — [docs/API.md](../docs/API.md).
- Все тексты интерфейса берутся из `resources/locales` через `t("ключ")`. Русский и английский переключаются в шапке.
- Права: шапка, разделы и кнопки показываются по списку `user.permissions` из API. Скрытие — только для удобства, проверяет права бэкенд.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `nginx.conf` | настройка веб-сервера: отдаёт фронтенд и папку `resources` (иконки) |
| `src/style.css` | минимальная разметка (заменяется настоящим дизайном) |
| `src/app.js` | шапка, маршруты, отрисовка страниц |
| `src/api.js` | все запросы к API: токен, язык, ошибки |
| `src/i18n.js` | загрузка переводов, функция `t()` |
| `src/session.js` | текущий пользователь, `can("permission")` |
| `src/ui.js` | помощники: `h()` для создания элементов, `icon()` для иконок, деньги, даты, сообщения |
| `src/infinite.js` | бесконечная прокрутка и кнопка «Наверх» |
| `src/router.js` | действия при уходе со страницы и после отрисовки |
| `src/components.js` | карточки товара и новости, таблица характеристик, листалка страниц |
| `src/pages/*.js` | страницы: главная, каталог, товар, новости, конфигуратор, вход, корзина, кабинет, админка |

## Страницы

| Адрес | Страница | Кому |
|---|---|---|
| `#/` | главная: акции, скидки, хиты, новости, факт | всем |
| `#/catalog` | каталог с фильтрами и бесконечной прокруткой | всем |
| `#/product/:id` | карточка товара | всем |
| `#/news` | новости с бесконечной прокруткой | всем |
| `#/builder` | конфигуратор ПК | всем (сохранить — после входа) |
| `#/login`, `#/register` | вход и регистрация | гостям |
| `#/cart` | корзина и оформление заказа | после входа |
| `#/account` | профиль, заказы, бонусы, сборки | после входа |
| `#/admin` | админка, разделы по правам | `admin.access` |

## Иконки

Лежат в `resources/icons` по группам (навигация, кнопки, категории, статусы заказов, роли…). Все сразу: http://localhost:5173/resources/icons/preview.html. Подключение: `icon("navigation/cart")`. Список — [resources/icons/README.md](../resources/icons/README.md).

## Правила

- Текст из API вставляется только как текст (`h()` никогда не использует `innerHTML`), поэтому данные не могут подсунуть на страницу скрипт.
- Новый текст в интерфейсе — новый ключ в `resources/locales/ru.json` и `en.json`. `./run.sh locales` и автотесты проверят, что ключ есть в обоих файлах.
- Картинки показываются только по ссылкам `http(s)://` или `/...`.
